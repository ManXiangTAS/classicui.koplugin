# 原生界面与基础控件接管清单

2026-10-23，墨页 0.5.0-test.2。支持的 KOReader 源码固定为 `9192014d8bd82a91dc1012473be0f238dedfdb54`，桌面运行包为 v2026.07.1，与目标 v2026.07.2 同源。Voyage 真机未运行本次修改。

## 本次已完成的共同样式

标准矩形窗口、按钮、选择控件和进度条统一以直角绘制。普通提示、固定高度报告、等宽诊断、指定字体提示、带图片提示都在覆盖范围内。关闭、取消、确认、输入、滚动、超时、回调和返回栈仍由原控件处理。

采用 `FrameContainer.paintTo` 和 `ProgressWidget.paintTo` 两个可撤销的公共绘制适配。既有窗口、运行时新建的窗口、重新初始化的窗口，以及按钮按下反馈都会经过此处；第三方使用标准控件时无需逐个登记。没有更改 `Size.radius`，没有改 KOReader 核心文件，没有替换文档或插件的数据逻辑。

绘制时临时使用直角，随后恢复对象原有半径，子控件绘制抛错时也恢复后继续抛出原错误。这样不会破坏原生按钮通过半径判断高亮/还原状态的协议，也不会改变控件宽高、点击区域、焦点边框或调用者指定的字体。

真正的圆形框体保留：绘制宽高相差不超过1像素，且半径已达到半宽时视为圆形。原生单选圆点、图标内的圆形和墨页设备面板的圆形按钮不受影响。插件自有框体可设 `_eink_keep_shape=true` 保留外形；明确需要将圆形框体方形化时可设 `_eink_force_square=true`。这两个标志应设置在 FrameContainer 实例上。

## 可复查的源码盘点

- `constructors.csv`：164个文件、1,059处标准控件创建调用。包含宿主及随 KOReader 提供的插件，不包含用户另外安装的任意插件。这是静态调用点数量，不是1,059个独立功能或通过测试的路径。
- `rounded-frames.csv`：43处非零/动态半径候选，包含按钮反馈、弹出菜单动态半径及有意保留的圆形。
- `inventory.json`：固定提交、源文件哈希和直接圆角绘图调用位置。
- 固定源码中的三个直接圆角矩形绘图调用：公共 FrameContainer、公共 ProgressWidget 已承接；Wi-Fi 分页指示器没有传入半径，底层实际绘制的是直角，因此无需增加全局图形补丁。

重新生成：`python3 tools/audit_native_controls.py /path/to/koreader/source`。脚本只读源码，不运行动态菜单、回调、网络或设备操作。
