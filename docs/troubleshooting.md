# 常见问题

**0.6.0 / 0.6.1 点击书库按钮后退出**：请完全退出 KOReader，手动覆盖安装 0.6.2 再重新启动。已根据日志确认并修复 `screen.lua` 中 `viewport_h` 未初始化导致的点击崩溃；0.6.1 的反馈兼容处理没有覆盖这处问题。无需删除个人设置或书库。若仍退出，请提供新的 `koreader/crash.log`、设备型号和 KOReader 版本。

**插件没有出现**：确认目录为 `koreader/plugins/einkfrontend.koplugin/`，`main.lua` 就在这个目录里，没有多套一层目录；安装后重启 KOReader。

**Kindle 按钮没有反色反馈**：0.6.1 / 0.6.2 曾暂时停用该效果，0.6.3 已恢复。请安装新版并确认 KOReader 的按钮反馈开关没有关闭；若当前运行中发生过反馈刷新异常，重新启动后会再次尝试。

**同时启用了 SimpleUI 或其他前端**：同时接管相同入口可能冲突，请择一启用，再重启。部分第三方插件拥有自己的界面，仍会显示原生窗口。

**传书网页打不开**：两台设备需连接同一 Wi-Fi，且路由器没有启用设备隔离；关闭旧页面，在 Kindle 重新开启传书、重新扫码。休眠、退出或会话到期后，旧地址失效。

**书已送达但没出现**：等待书库扫描，检查当前筛选条件和接收目录。重新扫描书库不会移动书籍。

**书名或作者没有写进 EPUB / PDF 内部**：这是本机显示信息，保存在 KOReader 共用元数据中；原文件内容保持不变。脱离 KOReader 导出文件时不会把这些覆盖值嵌入原书。

**阅读回报没有变化**：确认填写了大于0的购机投入；本书已填价格，并设为「已完成」。未填价格不会自动估价，同一上传文件不会重复累计。点击主页刷新图标可立即更新。

**原生屏保选项不可用**：需要设备上存在可读取的 Kindle 原生屏保图片。选项会自动查找本地目录，找不到时不替换当前壁纸；不同固件和机型可能不同。

**想恢复原来的界面**：设置 → 维护与恢复 → 前端开关与恢复。无法进入时，退出 KOReader 后移走插件目录即可，保留书籍和设置。

反馈问题时请附设备、固件、KOReader版本与复现步骤；截图中不要保留临时二维码、访问密钥或个人信息。
