# 墨页 · ClassicUI 0.7.4

本版新增文件夹分类导入收藏，统一阅读排版入口，并修复半号字号报错和主页部件关闭受阻的问题。

## 新功能怎么用

### 把旧书库文件夹变成收藏

1. 打开「设置 → 书库与文件 → 文件夹转为收藏」；也可以在书库的「收藏」页打开右上角菜单，选择「管理收藏 → 文件夹转为收藏」。
2. 选择包含分类文件夹的**上级目录**。例如原来是 `书库/文学/鲁迅/书籍.epub`，选择「书库」。
3. 查看预览中的「收藏名称 / 书籍 / 状态」三列。「新增」会新建收藏，「补入」只添加缺少的书，「已导入」无需再次操作。
4. 点击底部「导入 N 个收藏」。完成后点「查看收藏」，就能按原来的分类找书。全部已存在时会直接显示「全部已导入」。

以上例子会生成「文学」和「文学/鲁迅」两个收藏；父目录收藏包含子目录的书。所选根目录里散放的书不生成收藏，仍可在书籍页找到。

导入只建立收藏关系，**不移动书籍、不改原文件、不切换当前书库目录**。同名收藏只补入缺少的成员，可以重复导入。导入前会自动在 KOReader 的 `settings` 目录保存 `collection-before-folder-import.lua` 备份；每次导入会更新这份备份。位于当前书库目录之外的收藏成员也可正常显示、搜索和筛选。

### 从 Aa 打开阅读设置

阅读时点击顶部区域打开工具栏，再点击 **Aa**，直接展开字体面板，底部可切换「主题 / 字体 / 排版」。点击屏幕中央或底部不再触发这组菜单，也不会单独弹出它的导航栏。

### 调整主页部件

点击主页旁的铅笔，选择部件、整行或半行，并调整顺序。关闭部件始终允许执行；半行部件重新配对后，如果仍提示空间不足，可继续隐藏或调整，预览能完整放下一屏后再保存。半行表示宽度减半，高度会随内容变化。

## 修复与界面调整

- 修复保留29.5等原生半号字号时，修改字体、字重、对比度或应用主题报「数值超出范围」；字号按0.5步长调整。
- 文件夹导入改用紧凑预览，列表单独滚动，主要操作固定在底部；已导入项目不再误报需要合并。
- 收藏封面下方只显示书籍总数，去掉「符合筛选 / 收藏共」冗余文字。
- 修复取消半行部件后，因后续部件重新配对导致总高度增加，从而连关闭部件都被空间检查拒绝的问题。新增、扩宽和重排仍保留容量检查。

## 安装与升级

适配 **KOReader v2026.07.1 / v2026.07.2**。下载 `ClassicUI_0.7.4_install.zip`，完全退出 KOReader，备份原插件和设置后，把包内 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，保留目录名称，再重启。源码包用于查看和开发，无需同时安装。

本版通过199项本机逻辑、界面布局与构建检查；这些检查使用模拟设备与接口，未执行本版原生Linux模拟器、实际浏览器或Kindle真机验收。
