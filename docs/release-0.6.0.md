# 墨页 · ClassicUI 0.6.0

把设备，读成自己的。

墨页为 KOReader 带来统一的黑白阅读前端：自定义主页、独立书库、阅读工具与分层设置。

这台 Kindle，读回本了吗？新增「阅读回报」部件，填入购机投入与书价，让读完的每一本书，推动圆环向前。从故事刚开始，到已经回本，再到越读越值。数字是彩蛋，故事才是真正的回报。

网页传书也更直接：同一 Wi-Fi 扫码，拖入书籍，编辑书名、作者和可选价格，发送。书籍直接保存在设备上，同名文件不会覆盖；原网页精排已移除。

还有14种主页部件、即时布局预览与手机编辑、作者/系列/收藏书库、命名主题、目录与标注、中英切换、点击反馈和更容易操作的滚动条。

下载 `ClassicUI_0.6.0_install.zip`。完全退出 KOReader，把其中的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，保留此目录名称。适用 KOReader v2026.07.1 / v2026.07.2。部分第三方插件保留原生窗口，设备专用功能依硬件能力而定。
