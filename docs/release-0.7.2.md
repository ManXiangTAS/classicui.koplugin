# 墨页 · ClassicUI 0.7.2

整理前光与书籍操作，并修复异常恢复、网页编辑及打包问题。

- 自动调光使用亮度旁的小复选框；校准与学习偏好位于「设置 → 显示与刷新 → 前光」。仅在设备提供有效光感接口时可用。
- 下拉面板移除重复的前光电源开关，保留拖至 0 关灯和「＋」恢复亮度。
- 书籍长按菜单按阅读、书籍信息、整理书籍、文件操作分类；书库清理位于设置。
- 修正闲置自动变暗被误记为手动关灯或手动优先的问题。
- 修正传书最终保存失败后的重试、文件关闭失败后的会话清理，以及延迟扫描异常处理。
- 修正书籍删除后元数据清理失败的提示与返回收尾，保护书库维护的异步完成与重绘路径。
- 同步阅读与书库界面的书价、书库索引、主题和主页布局，防止旧设置副本覆盖新修改。
- 返回书库时保留局部阅读状态筛选；主题编号从现有记录恢复，损坏或重复记录保留原文件，保存后核对编号。
- 网页传书取消保留正确的取消状态，金额校验与设备端一致；阻止会话存储不再影响二维码连接。
- 手机主页编辑在失败恢复后可直接再次保存；同一临时会话内支持刷新页面。
- 修正 Windows 的 UTF-8 读取与 ZIP 路径问题；生成草稿不再提前隐藏已有正式版。

适配 **KOReader v2026.07.1 / v2026.07.2**。完全退出 KOReader 后，将安装包中的 **einkfrontend.koplugin** 覆盖到 **koreader/plugins/**，保留目录名与个人设置。升级前请备份原插件和设置。本版手动升级。

本次已执行本机 Python、Lua 策略/故障注入和网页脚本逻辑检查；Linux KOReader 模拟器、真实浏览器联调和 Kindle 硬件验收尚未执行。详细证据及范围见 docs/audit-0.7.2.md。生成 0.7.2 文件不等于已上传或公开发布 GitHub Release。
