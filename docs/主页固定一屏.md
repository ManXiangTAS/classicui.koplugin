# ClassicUI 0.4.0-test.3：主页固定一屏

- 设置入口中的 PagePress 统一改称“翻页键”，搜索 PagePress 仍可找到。原有设置和功能保留，无需重新配置。
- 主页只使用标题栏与底部导航之间的范围。上下滑动、拖动、翻页键和鼠标滚轮都不会移动主页内容；顶部边缘下拉设备菜单继续保留。
- 部件按当前屏幕可用高度安排。相邻半行部件等高；书架、统计表、热力图、柱图、时段分布和每日目标使用实际分配高度重新排版。文本保持可读字号，不将整个部件图片缩小。
- 一屏容不下新增部件时，编辑器会提示先隐藏部件或调整为半行。修改未应用时，草稿、预览和保存值保持一致。
- 旧版超过一屏的布局不自动删除部件。主页显示可容纳的部分并提示数量，编辑器标记超出的部件，允许逐步减少；所有部件能放入一屏后才可保存。
- 设备编辑器和手机编辑器使用同一份实际屏幕预览。手机端移除“预览上移/下移”，显示本屏部件数量；被拒绝的修改会恢复为最近一次有效草稿，还可继续编辑。

## 兼容与验证

配置结构仍是 v2，没有更改插件目录、模块 ID、收藏夹或书籍文件。首次读取旧布局不写配置。固定支持 KOReader v2026.07.1 / v2026.07.2 stable。

实际运行 KOReader 桌面程序，分别检查 600×800、1072×1448、1448×1072：默认主页、13 种部件的整行/半行与最小高度、所有半行配对、边界与点击区域、旧偏移清零、溢出恢复、编辑保存和书籍返回。手机编辑另以 Chromium 和真实 LuaSocket 服务检查容量拒绝后回退与继续编辑。测试隔离用户配置，未连接 Kindle 真机。

## 实现依据

参考 [SimpleUI](https://github.com/doctorhetfield-cmd/simpleui.koplugin) `engines/sui_screen_engine.lua` 对可用内容高度、同排部件高度和溢出提示的处理；本版依用户要求固定为单屏，未复制其前端 Lua。

`homefit.lua` 按可用范围分配行高，保留部件最小高度。`homewidgets.lua` 与 `homestatwidgets.lua` 按分配结果绘制；`screen.lua` 关闭主页滚动，但保留设置列表滚动。旧版滚动主页专项由 `tests/home049.lua` 替换，其他阅读导航和书库回归继续运行。验证结果位于 `test-results-049/`。
