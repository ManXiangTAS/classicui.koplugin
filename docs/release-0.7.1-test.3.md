# 墨页 · ClassicUI 0.7.1-test.3

- 长按书籍 → 删除书籍。确认后永久删除本机文件和对应书库记录；正在阅读的本书需先退出。主页的继续阅读、最近与待读书架也支持长按。
- 书库右上菜单 → 清理已删除书籍的数据。先扫描并列出数量与待处理书籍，再由用户确认清理。
- 清理当前书库内已经不存在的书籍残留：KOReader 阅读设置、可确认归属的封面和资料、封面数据库缓存、失效书库索引、最近阅读、收藏及本书价格记录。空的残留侧车目录也会移除。
- 历史阅读统计和热力图保留。现存书籍及其笔记、同名多格式的共享资料、哈希共享元数据和未知文件保留。预览后恢复的书籍或发生变化的数据会跳过；无法读取的存储设备不清理。

清理入口同样位于「书库选项」和「设置 → 维护与恢复」。发生权限错误时显示失败或跳过数量，可以再次扫描重试。

本测试包包含之前的全 Kindle 能力检测、自适应前光、分模式亮度记忆等改动。完全退出 KOReader 后，覆盖安装 `einkfrontend.koplugin`。正式版不自动更新。
