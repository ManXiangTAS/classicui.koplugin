# 墨页 · ClassicUI 0.7.4-test.1

- 阅读时，点击顶部工具栏中的 **Aa**，直接展开主题／字体／排版面板。中央和底部点击不再弹出排版面板或其独立导航条。
- 新增 **文件夹转为收藏**：从“收藏 → 管理收藏”或“设置 → 书库与文件”进入，选择旧书库的上级目录，预览后确认导入。
- 每个含书子目录生成一个原生收藏；嵌套目录使用相对路径命名，例如 `文学/鲁迅`。父目录收藏包含其子目录书籍，所选根目录散放的书籍不生成收藏。
- 同名收藏仅补入成员，保留既有成员、排序、默认收藏和文件夹规则；重复导入不会重复添加。本功能为一次性导入，后续新增书籍可再次扫描导入。
- 不移动书籍，不修改当前书库目录。导入前保存 `collection-before-folder-import.lua`，并复查目录与书籍身份；保存失败尝试恢复原收藏。
- 补齐当前书库目录之外的收藏成员显示、搜索、筛选与计数。

这是本地测试版，适配范围仍为 KOReader v2026.07.1 / v2026.07.2。完全退出 KOReader，备份插件和设置，再将安装 ZIP 内的 `einkfrontend.koplugin` 放入 `koreader/plugins/` 并重启。

验证范围：本机逻辑、模拟文件系统与故障注入、发布策略及真实 ZIP 构建；未执行本版的 Linux KOReader 集成、真实浏览器或 Kindle 真机验收。自动前光集成脚本中原有的过时断言不在本次改动范围内。
