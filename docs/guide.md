# 墨页使用指南

## 安装与升级

完全退出 KOReader，再把安装包内的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`。保留插件目录名称、书籍和 KOReader 设置。启动后在插件管理中启用「墨页 · ClassicUI」。首次使用可按向导选择书库及传书目录，默认 `/mnt/us/documents/ManualBook`；之后可在「设置 → 书库与文件 → 传书与书库」修改。

## 主页与布局

点「主页」旁的铅笔，选择显示或隐藏的部件、整行或半行、排列顺序，再保存。预览会随修改更新。主页固定一屏，放不下时请先隐藏一些部件或改为半行。编辑器中的手机编辑入口可生成临时二维码，在同一 Wi-Fi 的手机或电脑浏览器中编辑、看预览并保存；关闭编辑器、休眠或会话到期后，连接失效。

关闭部件始终允许执行。半行部件会重新配对，关闭后若预览仍提示超出，可继续隐藏或调整；一屏放下全部启用部件后才能点保存。半行只改变宽度，并不保证高度减半。

## 阅读回报

在主页编辑中开启「阅读回报」，轻点部件，填写「购机投入」。上传时填写本书价格，或在书库长按书籍进入详情后补填。书籍详情的「阅读状态」可以设为已完成。

计算方式：**已完成书籍的填写价格合计 ÷ 购机投入**。所有金额均按人民币元记录，最多两位小数。没有完成的书不计入；未填价格不计金额，填0表示免费。相同上传文件按一份记录计入，采用最近一次填写的价格；重复阅读不重复计入。取消完成状态、清除价格或移除书籍后，进度会相应变化。它是阅读记录的小部件，不代表实际省下的钱。

## 书库与收藏

在书籍、作者、系列、收藏之间切换，选择封面墙或列表，使用筛选、排序和搜索。长按书籍后，按「阅读 / 书籍信息 / 整理书籍 / 文件操作」分类进入。书名、作者和价格在「书籍信息」中；收藏、系列和卷序在「整理书籍」中。修改书名、作者和系列只写入 KOReader 本机元数据，不重写原书内容。

长按书籍后选择「文件操作 → 删除书籍」，确认后永久删除本机文件与对应书库记录。正在阅读的本书须先退出；累计阅读统计与热力图保留。主页的继续阅读、最近和待读书架也支持长按。

在「设置 → 书库与文件」选择「清理已删除书籍的数据」，先扫描预览，再确认清理当前书库内已删书籍的阅读设置、封面缓存和失效记录。重新放回的书籍、共用资料、哈希共享数据和未知文件会保留；权限失败可重新扫描重试。详细范围见[删除与清理说明](book-maintenance.md)。

收藏页的三个点中进入「管理收藏」，可新建、重命名、管理成员及控制是否在书库显示。隐藏收藏夹不会删除它或其中的书籍。

旧书库按文件夹整理的分类，可以在「管理收藏 → 文件夹转为收藏」或「设置 → 书库与文件 → 文件夹转为收藏」导入。选择包含分类文件夹的上级目录，检查预览后确认。每个含书子目录成为一个收藏，嵌套目录用 `文学/鲁迅` 这样的相对路径命名；父目录收藏包含子目录的书。所选根目录散放的书籍不生成收藏。同名收藏只补入成员，重复导入不会重复添加，原文件位置和当前书库目录保持不变。导入前会在 KOReader settings 目录保存 `collection-before-folder-import.lua` 备份。

预览列表分为收藏名称、书籍数量和状态：“新增”表示新建收藏，“补入”表示只添加缺少的书，“已导入”表示无需操作。全部书籍已在收藏中时，直接点底部“查看收藏”；需要导入时，底部显示“导入 N 个收藏”。

## 阅读工具

在阅读页点击顶部区域打开工具栏，点击其中 Aa 直接展开字体、排版与主题菜单。点击屏幕中央或底部不会打开该菜单或其独立导航栏。工具栏也提供目录、书签与标注、搜索和统计。字号支持0.5步长，保留29.5等原生半号设置。只有「默认」为内置主题，喜欢的设置可以另存。关闭按钮会关闭整个设置面板。

滚动列表右侧留有独立操作区，可以轻点上下箭头、点轨道、直接拖动或长按拖动。若 KOReader 的界面点击反馈被主动关闭，墨页也不闪烁。

## 网页传书

1. Kindle、手机或电脑连接同一 Wi-Fi。
2. 在「传书与书库」开启网页传书，扫码打开临时地址。
3. 选择文件，展开文件项，填写标题、作者与可选价格，发送。
4. 显示已送达后，在 Kindle 书库阅读。传完可关闭传书。

单文件上限200 MB，每次20个文件。相同文件名自动加序号。手机或电脑上的原文件不变；接收文件以填写的书名命名，保留格式扩展名。元数据或价格保存失败时会单独提示，已经完整接收的书籍仍保留，可在详情补改。0.6.0 已移除原网页精排功能。

临时地址含访问密钥，请勿转发。传书会在30分钟后、休眠或退出时结束；未完成的临时文件会清理。默认仅局域网传输，不连接 Amazon 云端。

## 前光

下拉面板亮度旁的「自动调光」小复选框直接控制开关。「设置 → 显示与刷新 → 前光」保留亮度、自动调光开关与自动调光设置，有暖光的设备还可调整色温。进入「自动调光设置」选择暗处亮度、明亮处亮度和明亮环境标准；记忆和检测各有独立页面。首次开启以当前非零档位初始化，建议到最暗阅读环境设置舒适亮度；手动调亮不会改写暗处基准。开启立即开始调整，之后每 60 秒检测；唤醒立即判断并在 1 秒后复查。手动调整保持到环境使基础目标档位改变，手动关灯会保持关闭。亮度数字位于圆形滑块正上方，随滑块移动并使用非加粗字体。

## 输入与设备设置

普通文本输入框上方的「中 / EN」可快速切换。中文候选支持点选和翻页；切到英文时保留尚未选字的拼音。已启用其他拼音插件时，墨页会让出候选栏。

「设置 → 设备与系统 → 屏保 → 壁纸」可选「使用 Kindle 原生屏保」，按本机可找到的图片目录工作；缺少原生图片时保留原设置。此选项使用 KOReader 的随机图片屏保模式，不能运行 Kindle 原生屏保程序。

Voyage 的翻页键设置会按设备能力显示。时间与日期可选择时区并手动联网校时，网络和系统时间写入能力依设备而定。

## 恢复原生界面

进入「设置 → 维护与恢复 → 前端开关与恢复」，临时打开原生菜单或停用前端。如果界面无法启动，完全退出 KOReader 后移走 `plugins/einkfrontend.koplugin`，保留书籍和设置，再重启。插件只支持手动安装与升级。
