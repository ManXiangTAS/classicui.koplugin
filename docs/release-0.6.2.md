# 墨页 · ClassicUI 0.6.2

修复进入书库后，点击按钮会退出 KOReader 的问题。

- 根据 Kindle Voyage / KOReader v2026.07.2 的日志，定位到书库布局遗漏初始化可视区高度。点击处理在执行按钮操作前读取该值，导致异常退出。
- 书库和通用列表现在都会初始化正确的可视区高度；普通按钮跳过滚动条点击处理，页面切换也不会沿用旧高度。
- 保留 0.6.1 的 Kindle 点击反馈兼容处理，本次没有重新启用反色效果。

新增用例已在修复前复现与报告相同的异常，修复后三种模拟布局的相关检查通过。Kindle 真机效果仍需验证。

请完全退出 KOReader，将 `ClassicUI_0.6.2_install.zip` 中的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，然后重新启动。适用 KOReader v2026.07.1 / v2026.07.2；无需删除个人设置或书库。本版仍采用手动更新。
