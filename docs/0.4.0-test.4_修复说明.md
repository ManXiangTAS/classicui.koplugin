# 墨页 0.4.0-test.4 测试版

本次根据 Voyage 5.13.6 反馈调整翻页键设置和主题。

- 翻页键：修复唤醒时驱动被系统暂时占用后只应用一次的问题。最多短时重试4秒；成功后清除历史错误，休眠和退出取消任务。不强制解除系统锁定。当前忙状态显示“系统占用”，错误提示不再包含代码路径。
- 说明移至“翻页键”标题旁的信息图标，不占设置列表行，也不显示历史“检查按压力度”行。
- 主题仍为双列图标加文字，只内置“默认”。移除误加的普通、写实、舒适和临时自定义预设，保留实际保存的全部主题，不按名称删除用户数据。默认采用 KOReader 当前全局默认并继承后续默认调整。
- 主题图标改为同一套 Material Symbols Sharp 排版图标，移除小人。保存当前设置、管理主题功能保留。
- 升级不自动改变当前书籍排版；旧预设标识不再对应主题时不强选其他主题，用户可以保存当前排版或主动选择默认。

安装：退出 KOReader，将安装包内 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，保持目录名与现有配置不变，然后重启。

验证包括三种屏幕几何的真实 KOReader 渲染、主题及配置持久化、模拟驱动锁定/恢复/回滚、延迟任务取消、主页、设置与阅读回归。原生截图见 README；完整测试证据见 `test-results-050/combined-summary.json`。

尚未在 Voyage 实机复测。照片只能确认发生过系统占用错误，不能仅凭截图确定底层固件的占用原因；模拟回归通过不等于真机通过。若仍持续显示系统占用，需要保留触发步骤及 KOReader 日志继续定位。
