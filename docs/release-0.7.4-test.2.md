# 墨页 · ClassicUI 0.7.4-test.2

- 修复阅读排版提示“数值超出范围”：KOReader 原生支持 29.5 等半号字号，旧校验只接受整数；排版保存会校验全部字段，所以更换字体、字重和对比度也会被阻止。现在接受12—255之间的半号字号，并按0.5步长调整，保留原值。
- 重做文件夹转收藏的预览：来源和整体结果置顶，列表按“收藏名称／书籍／状态”展示；主操作固定在底部，长列表独立滚动。
- “新增”创建收藏，“补入”仅添加缺失书籍，“已导入”无需操作。已有收藏包含全部书籍时显示“全部已导入”，按钮直接进入收藏。
- 根目录散放书籍以一行说明保留原样；收藏页名称下方只保留“8 本”等数量。

本地测试版，适配 KOReader v2026.07.1 / v2026.07.2。安装前完全退出 KOReader 并备份插件与设置，用安装包内 `einkfrontend.koplugin` 覆盖插件目录后重启。

验证包括模拟存储中的半号字号排版保存、目录导入回归、页面状态及多种尺寸的布局检查、真实 ZIP 构建与源码摘要。布局图片来自应用页面代码配合模拟绘制后端和桌面字体，不是 Kindle 截图。本版未执行 Linux KOReader 集成或 Kindle 真机验收；原自动前光集成测试的过时断言仍待处理。
