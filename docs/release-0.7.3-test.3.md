# ClassicUI 0.7.3

## 前光设置精简

前光首页：亮度、自动调光、自动调光设置；有暖光的设备显示色温，手动优先或关灯时显示“恢复自动调光”。无光感设备只显示手动控制。

自动调光设置：暗处亮度、明亮处亮度、明亮环境标准、亮度记忆、状态与检测。浅色/深色模式显示在页面副标题。记忆列表和调试数据按需查看；清除记忆只在存在记录时出现。原本长篇注释放入帮助。

明亮环境标准提供 500 / 1000 / 10000 lux 预设，也可以使用当前环境或自定义数值。预设名称只是便于选择的参考，具体以传感器读数和阅读感受调整。

## 自动调光

- 启用立即计算并开始逐档调整，正常每 60 秒读取环境光，渐变每 2 秒一档。
- 对数曲线新增可配置的明亮处亮度和明亮环境标准。默认明亮处 0 档、标准 10000 lux。暗处沿用已有校准值，首次启用仍以当前非零亮度为暗处起点。
- 0–5 lux 统一视为暗处；曲线从 5 lux 平滑衔接，避免参考插件 5→6 lux 的跳变。
- 手动亮度没有固定超时。环境没有改变到使基础曲线目标档位变化时，保持手动选择；学习本次调整不会误触发恢复。
- 手动关灯保持关闭，只有明确恢复自动或重新启用才解除。自动因环境明亮而关灯则可以在环境变暗后重新亮灯。
- 唤醒立即采样并判断，1 秒后复查，再进入每分钟检测。复查窗口内的系统亮度恢复不会被记成手动操作。手动关灯、其他控制器占用和设备故障保护依然生效。
- 暗处、明亮处、环境标准和学习记忆按模式保存。沿用已有校准与记忆；明确修改明亮处设置时，清理当前模式中与该亮度范围冲突的明亮环境记忆。

## 滑块显示修正

亮度数字改到圆形滑块正上方，并随滑块水平移动，使用非加粗字体。下拉面板、手动亮度和暗处/明亮处设置窗口统一；圆形滑块恢复较小尺寸。

## 安装与验证

完全退出 KOReader，覆盖 koreader/plugins/einkfrontend.koplugin 后重启。请停用其他自动调光控制器。

本机验证使用 Fengari Lua 5.3、模拟传感器/设备接口和网页脚本替身。新增回归覆盖曲线边界、手动保持、唤醒复查、设置导航与输入验证、数字位于滑块正上方的绘制坐标。KOReader Linux/LuaJIT、真实浏览器和 Kindle 真机验收未执行；字体观感、实际光感和耗电仍需真机确认。具体结果见交付包 verification/。

参考设计：用户提供的 autofrontlight.koplugin.zip，其 main.lua 的 Git blob SHA1 为 c77db441004e74e1e6a1dabec486a02919786e4c，与 https://github.com/kermitine/kindle-voyage-koreader-autofrontlight 的公开代码一致。本次借鉴可调曲线、环境目标变化后接管和唤醒复查的交互思路。
