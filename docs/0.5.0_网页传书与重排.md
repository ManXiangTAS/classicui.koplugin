# 墨页 0.5.0-test.1：网页传书与可选 EPUB 重排

设置页右上角的搜索图标改为三个点，打开后提供“搜索”和“重启 KOReader”。搜索继续按当前页面范围工作；重启会先确认并调用 KOReader 原生保存与重启。

首次自动进入墨页时显示传书向导。可以采用 `/mnt/us/documents/ManualBook`，选择已有文件夹，或输入并创建新目录；也可选择保留当前书库、稍后设置。之后在“设置 → 书库与文件 / 网络与同步 → 传书与书库”更改目录或重新运行向导。该目录同时作为墨页书库根目录。修改目录不移动、删除旧书，旧目录仍保留在设备上。

“开启网页传书”会打开临时局域网 HTTP 服务。手机或电脑和 Kindle 连接同一 Wi-Fi，扫描设备显示的二维码，或手动输入包含 `#` 后临时密钥的完整地址。无需连接亚马逊，不需要公网、不需要亚马逊账号。可拖入或多选最多20本书，每本最多200 MB；接收端按64 KiB分块落盘，不把整本书常驻 Kindle 内存。预留16 MB可用空间，同名文件自动增加序号。完成后自动重新扫描书库。

**EPUB 重排默认关闭**。选择 EPUB 后可打开“高级设置与预览”，调整首行缩进、行距、段间距、页边距、标题大小和自动识别标题；电脑左右比较，手机切换原版与精排结果。点击“使用此排版”后才启用重排，再点击发送。批量 EPUB 沿用当前参数，非 EPUB 按原文件发送。生成的文件名带 `_精排`，原文件不变。KOReader 阅读时的行距、边距和嵌入样式开关也会影响最终效果。

重排在手机 / 电脑浏览器本地完成。为控制内存，重排文件限50 MB、解压后总量128 MB、单资源32 MB（XML 章节另限8 MB、CSS另限2 MB）、最多10000个资源；拒绝异常压缩比、ZIP64、加密/混淆、数字签名、路径穿越、重复路径、符号链接、XML实体、过深CSS嵌套、CRC错误和非规范 XHTML。遇到不支持的 EPUB 可取消重排，直接发送原书。重排支持 EPUB，不把 PDF、AZW、KFX 转换成 EPUB，也不处理 DRM。

预览采用不允许脚本和同源权限的沙箱；使用本地 data URL 显示插图，禁止远程资源访问。目录、原资源路径、插图字节、脚注锚点和链接在测试中保留。复杂固定版式、公式、竖排、互动书不建议未经逐章检查就重排；可关闭重排保留原样。

临时服务30分钟后关闭。休眠、退出墨页、停用插件、修改目录或手动关闭服务也会让地址失效。未完成上传在取消、关闭服务或两分钟无传输后清理；异常断电留下的隐藏 `.moye-upload-*.part` 临时文件不会进入书库，可在退出 KOReader 后清理。接收端不提供任意文件下载、远程目录修改或命令执行。HTTP不加密，请在可信 Wi-Fi 使用，不要转发完整地址或配置公网端口转发。

本版对真实 KOReader 模块、LuaSocket HTTP、Chromium 页面和实际测试目录做回归；未在 Voyage 5.13.6 或 Kindle 2022 上复测。设备防火墙、Wi-Fi隔离、实际传输速度、残影和唤醒行为仍需实机确认。教程中的原生界面为桌面模拟，浏览器段落为真实录屏，所有书籍与数据均为原创测试素材。

第三方：上传页面按用户提供的 Send to Kindle 页面参考重新设计，无亚马逊品牌图片、脚本或账号数据。EPUB 重排基于用户提供的离线工具进行集成与加固；JSZip 3.10.1 和其 pako 依赖随包保留 MIT 许可。项目插件代码保持 AGPL-3.0-or-later。
