# 墨页 · ClassicUI 0.7.0

让阅读返回更连贯，让点击和滚动更可控。

- **阅读返回**：从书中返回墨页主页或书库，保留打开书籍时的位置。
- **点击反馈**：改善 Kindle 上间歇性看不到反色的问题；下拉面板按圆形图标反馈，不再整块反色。
- **滚动条**：到顶、到底后直接停住，快速拖动松手不再反向回跳。
- **网页传书**：蓝色横幅、设备插图和拖放图形与 Send to Kindle 页面一致，支持编辑书名、作者及可选价格，文件直接保存到本机。
- **稳定性与接口校验**：完善取消上传、请求校验、响应处理和错误恢复。

适配 **KOReader v2026.07.1 / v2026.07.2**。请下载 `ClassicUI_0.7.0_install.zip`，完全退出 KOReader 后，将其中的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，然后重新启动。无需删除个人设置或书库。

本版采用手动安装与升级。以前的测试版继续隐藏；新用户请使用本次安装包。
