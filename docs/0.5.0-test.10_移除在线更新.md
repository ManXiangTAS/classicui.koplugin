# 墨页 0.5.0-test.10：移除在线更新

按用户要求完全撤销插件在线更新，改为手动安装。此前 13 个 Release 已转为草稿，从公开发布列表下架；不删除 Git 历史。

## 安装

1. 完全退出旧版 KOReader。下架不会停用已经安装的副本，不再使用旧版检查或安装更新。
2. 从本次 GitHub Release 下载 `ClassicUI_0.5.0-test.10_install.zip`。
3. 通过 USB 将 ZIP 中的 `einkfrontend.koplugin` 文件夹覆盖到 `koreader/plugins/`，保留该文件夹名称。
4. 重启 KOReader。本版会停用旧更新设置，删除插件专用的 `einkfrontend.koplugin-update` 暂存目录；保留其他设置、书籍和插件目录内的用户文件。

## 变更

- 移除更新菜单、更新源、自动检查、下载任务及启动/休眠/唤醒更新挂钩。
- 无 GitHub 或中转在线回退，不携带更新服务器地址。
- 不加载待安装清单、不执行暂存包，不根据旧 journal 恢复或替换当前入口。
- 旧更新模块被覆盖成无网络、无任务、无安装能力的禁用占位文件，使正常覆盖安装也能停用旧模块。
- 清理专用更新缓存时先移除待安装标记，再删除缓存；符号链接只解除自身，不遍历外部目录。清理失败也不会执行这些缓存，且不会阻止正常使用前端。
- 构建不再生成在线安装所需的 UPDATE_MANIFEST.json。保留离线下载包的 SHA-256 文件，后续升级一律手动安装。
- 移除当前分支的在线更新协议文档、实现测试与相关地址引用；历史源码仍可在 Git 历史中查看。

书库、主页、阅读菜单、输入法、Kindle 图片屏保、局域网传书和主页编辑等原有功能保留。此次操作不包含服务器修复或对已安装设备的入侵判定。

## 验证

每种布局使用独立 KOReader 运行目录和完整插件副本，预置自动检查/自动安装设置、待安装包、恢复记录和会写入哨兵的旧入口。新版本正常加载，不执行旧入口、不替换当前 main.lua，旧设置与专用缓存被清理；启动、休眠、唤醒和关闭均未发出更新请求。

另检查旧菜单路由、覆盖占位模块、损坏缓存、符号链接、设置保存失败与重复清理，并回归输入法、屏保和设置首页小菜单。实机行为仍待用户验收；测试没有访问原中转服务器。
