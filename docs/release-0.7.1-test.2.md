# 墨页 · ClassicUI 0.7.1-test.2

在自动前光测试版基础上，参考 ZenOS 选取两项适合墨页的细节：

- 浅色与深色模式各自记住暗处亮度、环境光偏好。切换界面模式后重新稳定采样，旧模式的偏好不会混入新模式。
- 关灯后在下拉面板点“＋”恢复最近非零亮度，再次点按继续逐档调节。恢复属于手动操作，自动控制继续暂停 15 分钟，或由用户点“恢复自动”提前恢复。

入口：设置 → 显示与刷新 → 自动前光。原有暗处校准、光感过滤、逐档过渡、记忆开关、手动关灯锁定和休眠停止采样保持有效。每种界面模式各保留最多 12 个环境偏好，清除记忆只影响当前模式。

完全退出 KOReader 后，覆盖安装 `einkfrontend.koplugin`。Kindle 请先关闭原生自动亮度。此版仍需 Voyage 验证真实 Lux、普通 / 无框架模式、休眠恢复与功耗；不自动发布正式版。
