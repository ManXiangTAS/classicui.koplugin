# 删除书籍与清理残留

## 入口与行为

长按书库书籍或主页书架中的书籍，进入详情后选择“删除书籍”。确认框显示书名、完整路径及删除范围。执行时重新核对文件身份；文件发生变化、是链接/目录或仍在阅读时拒绝删除。只有书籍文件成功删除后才移除对应数据；无法删除文件时保留全部记录。

“书库菜单 → 清理已删除书籍的数据”只扫描当前可读取的书库根目录。先预览，再确认清理；扫描本身不删除数据。用户在电脑或其他工具中删书、再重新扫描书库后，仍能通过残留 `.sdr` 找到可清理数据。

范围：可确认归属的 `metadata.<格式>.lua` 及备份、孤立的自定义封面和元数据、旧式路径历史设置、封面数据库对应行、失效书库/收藏/最近阅读和价格记录，以及空的孤立 `.sdr` 目录。累计阅读统计、页数、时长、热力图不清理。Kindle 原生应用的未知侧车文件不自动删除。

## 保留规则

- 只有确定文件不存在（ENOENT），且原书库根目录仍可读取时，才纳入计划。权限错误、链接路径或存储设备身份变化会跳过/终止，不把离线存储当作已删书。
- 不跟随扫描中的符号链接；清理前再次验证祖先路径、文件 inode/设备号/大小/时间和 SHA-256。预览后恢复的书籍或替换的数据会保留。
- 同名不同格式仍在时，只清理缺失格式自己的阅读设置，保留共用封面和自定义资料。正在阅读但已被外部工具删除的文档也保留其共享数据。
- 不按缺失路径清理哈希共享元数据，以免移除同内容副本的笔记和设置。未知文件及目录不递归删除；目录仅在为空时移除。
- 只从当前书库范围选取封面缓存行。预览以只读 SQLite 连接读取，执行按完整路径参数绑定删除；不调用会迁移或重建整个封面缓存库的流程，不清理其他存储设备的缓存。
- 刷新所有活跃书库实例，防止阅读器与文件管理器用旧快照重新写入已删除记录。

## 调度与失败

扫描及清理采用可取消的有限任务。休眠或退出界面取消未完成任务。数据文件清理失败会保留该文件并报告，后续扫描可重试。书籍文件已删而部分索引或元数据清理失败时，会明确提示，不回报为“全部清理成功”。

单次扫描限制 32 层、50000 项；大型封面数据库最多读取 50000 行。残留文件大于 16 MiB 或无法读取时保留并计入跳过数量，避免异常数据使预览长时间阻塞。达到上限时显示部分扫描结果，可分目录处理。

## 验证

维护测试使用隔离设置和复制的示例书，不操作真实用户文件。覆盖确认/取消、删除失败、修改后拒绝、恢复文件、同名多格式、中央侧车、哈希副本、内容相同长度但发生变化、封面数据库路径与版本、链接、空目录、存储变化、当前阅读保护、入口与休眠取消。原始测试书和统计哨兵保持不变。
