# 0.4.0-test.1：主题、主页编辑与设置修正

2026-10-21。面向 Kindle Voyage / KOReader v2026.07.2 stable 的测试版本，固定源码与 v2026.07.1 一致。本轮未连接实机。

## 行为

阅读主题改为参考图的图标+文字双列：自定义用字样，预设与保存主题用人物小图，当前项有勾选和“当前主题”。保留保存与管理主题。预设使用当前有效默认字体，套用13项排版快照；切回自定义可恢复本次打开菜单时的自定义排版。手动修改会解除主题关联。默认/继承服务保留，操作行隐藏。X关闭面板和底部栏，子页面返回仍可返回所属栏目。

收藏根页移除创建入口；管理页仍可创建、增删成员、改名、删除和控制显示。隐藏只影响墨页书库的收藏根页；不会删除成员、改变原生收藏或关闭主页待读书架。显隐写入后读回验证，收藏改名和删除同时迁移显隐记录，出错恢复内存和原生文件。

阅读下拉去掉来源返回和同步；原生返回仍恢复阅读来源。时间页取消双行说明及范围介绍，统一数值和文字可见中心。维护页分四组，原生文件管理器的显示/排序设置集中到“原生界面设置”，全局设置搜索仍可找到这些选项。原生静态动作覆盖审计保留。

## 主页编辑

原先跳转多层设置改为全屏编辑器，同屏保留缩小的真实主页预览。点击预览放大，上下滑动预览切换可见区域；下方部件列表支持搜索、显示、半行/整行、排序。选中名言、书架、热力图、每日目标后，底部显示相应选项。修改更新草稿和预览，保存才落盘；退出有未保存修改时可确认放弃。

手机编辑与设备编辑共用同一草稿和版本号。浏览器提交旧版本时返回409，避免覆盖设备上的新修改；磁盘保存也比较编辑开始时的基线，避免覆盖其他窗口。保存失败保留草稿。浏览器可翻看长主页预览，图片由同一套KOReader绘制逻辑生成，不是另一份HTML模拟。

## 搜索

- 设置：静态及动态子菜单的全局索引，加前端、主页部件与时间入口；不会执行动作回调。动态构建有深度和节点上限，失败分支跳过，不停用前端。
- 主页编辑：13种部件及常用别名，含隐藏部件。
- 时区：全量地区、英文城市名及国家代码。
- 收藏管理、收藏成员和本书收藏：筛选当前页，清空恢复；成员搜索覆盖全部成员，不受屏幕可见行限制。
- 书库设置中的搜索直接进入书籍结果；分类内搜索保留作者/系列/收藏限制，提示文案说明范围。
- 阅读目录：包括折叠章节，搜索时显示匹配项；书签/标注按当前列表搜索，正文全文搜索仍使用原生引擎。

## 局域网编辑边界与回查

服务绑定本机IPv4与临时端口，无自动启动。192位随机密钥放在二维码URL片段，网页启动后移除片段，后续用Authorization头。检查Host/Origin，禁止CORS，限制JSON类型、字段白名单、32KiB正文、8KiB请求头、8层嵌套、4个客户端和5秒连接时间，拒绝重复长度、分块和流水线请求。没有文件读取、路径映射或命令执行API。

使用单调时钟计15分钟，不受校时跳变影响。关闭编辑器、停用、休眠和到期时清理监听、客户端、轮询、二维码与临时防火墙规则。Kindle只为该地址和端口添加临时规则，规则参数为校验后的IP和数字端口；创建失败回收已安装规则。防火墙实际效果与局域网连通仍待实机验证。连接为局域网HTTP，未宣称加密。

真实浏览器验证了搜索、修改、保存、读回、授权失败、跨来源、Host、媒体类型、分片请求和清理。输入中的HTML作为文本处理。另有布局、主题、收藏写入故障、会话到期、休眠、并发版本保护和原有标注回滚等回归。详细计数以combined-summary.json为准。
