## 发现与修复

| 范围 | 原行为及触发 | 0.7.2 处理 |
|---|---|---|
| 跨界面书库数据 | 阅读与文件管理界面各持一份 LuaSettings 快照；后续保存界面状态可能覆盖另一界面刚写入的书价、索引或返回记录。清理重新打开设置对象还会留下旧 Browser.settings 写入者。 | 同一书库使用同一个活动设置对象；扫描保存同步其他活动索引；清理保持原设置对象，避免旧副本回写。 |
| 跨界面主题与布局 | 不同 App 的主题和主页模型各自缓存，后保存的旧副本可能抹掉另一处新增主题或布局。 | 成功提交后同步同一设置文件的其他活动模型；未保存的编辑器仍通过原有 base 比较阻止覆盖新布局。 |
| 自动前光 | 原生闲置调暗或其他自动控制器的亮度变化先被当作手动操作，随后才检查控制权；可能触发 15 分钟暂停或手动关灯锁定。 | 先判断其他控制器是否占用；占用期间不记作手调，原生恢复后继续自动策略。 |
| 传书保存与清理 | 最终重命名失败后重复同步已关闭句柄；关闭失败保留死会话；延迟扫描入口异常未保护。 | 数据同步关闭与最终保存分离；摘要只完成一次；关闭失败撤销会话；延迟扫描用现有错误边界处理。 |
| 删除与书库维护 | 删除已成功，后续元数据异常却按删除失败退出；异步完成和重绘异常会逃出维护任务。 | 已删除后的收尾错误作为“部分清理未完成”返回；保护整个异步步骤，取消后续任务并保留错误原因。 |
| 阅读来源 | Browser.route 没有保留局部 status/statuses 筛选。 | 仅保留已知状态，并在返回和恢复书库分类时保留该局部筛选。 |
| 主题编号与损坏数据 | 计数器缺失/过期会产生重复编号，字符串计数器会使创建失败；重复 ID 或非数组记录可能被忽略；保存只核对主题列表。 | 从现有 ID 恢复安全计数；阻止重复/非数组损坏数据编辑，保留原文件；保存核对列表、版本与计数器，失败恢复完整旧设置。 |
| 网页传书 | 超长全零金额被网页接受但设备拒绝；解码响应时取消被改写成连接错误；禁止 sessionStorage 会阻止页面初始化。 | 金额与设备端 12 字符上限一致；保留 AbortError；会话存储不可用时仍使用二维码中的密钥。 |
| 手机主页编辑 | 失败恢复后 generation 没前移，新保存操作被旧取消屏障静默跳过；刷新页面会失去临时密钥。 | 成功恢复或重新载入后前移 generation；同一会话缓存有效密钥，存储不可用时也能使用原二维码。 |
| Windows 构建 | 默认 GBK 解码 UTF-8 元数据失败；反斜杠路径使构建在 docs/guide.md 处 KeyError，也不符合安装包筛选路径；ZIP 平台标识与摘要换行不统一。 | 显式 UTF-8、POSIX 归档路径、固定 ZIP 元数据和 LF 摘要。新增启动文件、全量插件内容、清单与重复构建检查。 |
| 发布草稿 | 构建草稿时就隐藏原正式版；后续发布失败会失去原公开下载。 | 未确认的草稿不动已有正式版；先验证新版本发布成功，再整理旧版本。 |
