# 墨页 · ClassicUI 0.7.3

本版整合前光体验改进、书库操作整理和稳定性修复。

- **自动调光**：启用时立即调整，此后每 60 秒检测环境光，亮度每 2 秒逐档过渡；支持暗处亮度、明亮处亮度和明亮环境标准。
- **手动与唤醒**：手动调整保持到环境变化导致自动目标档位改变；手动关灯保持关闭。唤醒后立即重算，1 秒后复查。
- **前光设置**：首页精简为亮度、自动调光及自动调光设置；亮度记忆、状态检测收进二级页面。亮度数字以细体显示在圆形滑块正上方，随滑块移动。
- **书库与菜单**：整理书籍长按菜单和删除入口，将书库维护收进设置，减少冗余说明。
- **稳定性**：修复跨界面旧设置覆盖、主题编号、返回筛选状态、书籍删除后的异常收尾，以及传书保存重试、失效会话和延迟扫描异常。
- **构建**：修复 Windows 打包路径，增加安装包主体与摘要校验。

适配 KOReader v2026.07.1 / v2026.07.2。下载 `ClassicUI_0.7.3_install.zip`，完全退出 KOReader 后，将 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/` 并重启。升级前备份原插件及设置。

验证：前一测试版记录 141 项本机检查通过；本次正式版版本统一后，重新通过 8 项发布策略与 5 项构建完整性检查。Linux/LuaJIT 模拟器、真实浏览器和 Kindle 真机完整验收尚未执行。
