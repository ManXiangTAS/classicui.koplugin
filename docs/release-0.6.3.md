# 墨页 · ClassicUI 0.6.3

恢复 Kindle 按钮的局部反色反馈。

- 点击自绘按钮时，按钮区域短暂反色，并在执行操作前恢复；继续遵循 KOReader 的按钮反馈开关。
- 保留反馈异常保护和 0.6.2 的书库点击崩溃修复。若反馈刷新异常，跳过效果并继续执行按钮操作。
- 已检查模拟 Kindle 分支的反色区域、恢复顺序、反馈开关和异常恢复，以及书库首次打开和反复重开的点击流程。电子墨水屏上的反馈速度与残影仍需实机验证。

请完全退出 KOReader，将 `ClassicUI_0.6.3_install.zip` 中的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，然后重新启动。适用 KOReader v2026.07.1 / v2026.07.2；无需删除个人设置或书库。本版仍采用手动更新。
