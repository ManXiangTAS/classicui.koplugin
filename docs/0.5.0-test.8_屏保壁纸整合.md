# 墨页 0.5.0-test.8：屏保壁纸整合

入口：**设置 → 设备与系统 → 屏保 → 壁纸 → 使用 Kindle 原生屏保**。

原先的独立“Kindle 原生屏保”页面已经移除。此选项复用 KOReader 的“在休眠屏幕上显示自定义随机图片”，自动检测 `/usr/share/blanket/screensaver` 或 `/usr/share/blanket/screensavers` 中的可读图片，并设置随机图片目录。图片从设备读取，不打包亚马逊图片，也不写入系统分区。

## 与其他壁纸的关系

- 这是一种壁纸选择，与书籍封面、自定义随机图片、阅读进度等正常切换；原生图片与自定义随机图片不会同时显示勾选。
- 新启用时只设置壁纸类型和图片目录，保留你的填充、拉伸、旋转、图片循环顺序和休眠文字。
- 切回自定义随机图片时恢复之前的自定义目录；切到书籍封面等其他壁纸时清除原生图片选择。
- 在 KOReader 的“自定义图片”中改成其他目录后，原生屏保选中状态随之取消。
- 检测不到可读原生图片时显示提示，不改变当前壁纸。可继续使用原有自定义图片目录选择器。
- 兼容旧版独立屏保页留下的备份。重新选择此项或改选其他壁纸时，撤销仍由旧版本保持的显示覆盖；保留你后来手动修改的设置。

功能仅在 Kindle 提供 KOReader 自选屏保能力时可用。显示的是原生屏保图片，休眠流程仍由 KOReader 负责。

## 搜索与验证

在全局设置搜索中搜索“Kindle”或“原生屏保”，可以找到同一个壁纸选项。搜索先扫描已注册的菜单项，再展开较大的动态字体或文件列表，避免动态列表耗尽扫描额度、遗漏后面的普通设置。

本轮使用固定 KOReader v2026.07.1 的真实菜单宿主、屏保图片加载器与渲染器，在 600×800、1072×1448 和 1448×1072 三种布局检查原生/自定义图片切换、选中状态、显示偏好保留、旧版配置、缺失目录、全局搜索、阅读器入口、非 Kindle 范围以及重复刷新。

合计 **99 次检查，33 个用例，9 次布局运行，失败 0**，包含现有输入法/屏保和设置更多菜单的相关回归。Kindle 能力和图片路径在桌面环境中模拟，物理 Kindle 的实际休眠仍待验证；其他历史测试没有加进本轮数字。

## 升级

已经安装 test.7：进入 **设置 → 维护与恢复 → 墨页更新**，使用“测试版与正式版”通道检查更新并安装。

更早版本：完全退出 KOReader 后，将安装包中的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，不要更改文件夹名称。现有书籍和配置保留。
