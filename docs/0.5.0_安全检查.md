# 0.5.0-test.1 检查与验证边界

本次新增功能的验证使用真实 KOReader Linux 运行时、LuaSocket 接收端、Chromium 和实际写入的隔离测试目录；不向真实 Kindle 写入文件。

- 接收端只接受设备端选定目录中的书籍 basename，拒绝路径分隔符、控制字符、隐藏文件名、不支持的扩展名及超限大小。逐级拒绝符号链接目录，独占创建临时文件，最终同名文件增加序号，不覆盖已有文件和符号链接。
- HTTP 要求精确 Host、同源 Origin（存在时）及临时 Bearer 密钥；无跨域授权，无远程目录修改、任意文件下载或命令执行接口。拒绝重复请求头、冲突长度、Transfer-Encoding、过长报文与请求路径。仅设备本地可设置根目录。
- 每次请求体不超过64 KiB，最多4个连接；书籍大小最多200 MB。写前检查可用空间并预留16 MB，完成前同步文件数据。取消、空闲超时、休眠、目录变化和停止服务均清理临时文件。检查中发现删除失败时原来会丢失清理路径，现保留路径、重试清理，阻止覆盖待清理状态。
- 防火墙只临时开放选定设备 IP 和随机端口，失败回滚已装规则；关闭时移除。会话固定30分钟，不长期驻留。网络与防火墙规则的实际 Kindle 行为仍需验证。
- EPUB 在浏览器本地处理，默认关闭重排。提前检查 ZIP 目录、资源数、大小、异常膨胀、CRC、特殊文件、路径穿越、重复名称；拒绝加密、混淆、签名和 ZIP64。XML限制体积、标签数量和实体，CSS限制体积与递归深度。
- 预览不使用有急切资源加载行为的 HTML 解析来读取原书，采用 XML 解析。书籍 iframe 不允许脚本或同源权限，图片转为本地 data URL；外部请求和事件处理器被阻止。检查中验证远程跟踪图片不发出请求，书中脚本不能访问上传页。
- 重排输出的 OPF、目录与图片字节保持一致，脚注、锚点和内部链接保留；mimetype 首项且不压缩。按原样发送时，对磁盘文件逐字节比较。支持取消后继续操作、刷新后继续使用会话、同名书保留与自动书库扫描。

上述是当前测试覆盖与源代码检查，不能证明不存在所有漏洞。无法模拟真实设备权限、磁盘断电和全部 EPUB 排版，也不替代 Kindle 实机验收。HTTP未加密，限可信局域网使用；关闭重排可保留原书样式。原生 KOReader 文档解析器与浏览器自身仍按各自版本的行为处理文件。
