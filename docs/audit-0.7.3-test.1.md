# ClassicUI 0.7.3-test.1

按用户确认的调光规则修正：

- 启用自动调光时立即读取当前环境、计算目标亮度并开始调光。
- 此后每 60 秒检测一次环境光，每次检测直接更新目标；移除旧版三次采样及两次确认造成的等待。
- 亮度继续每 2 秒逐档过渡，过渡期间不额外读取环境光。仍检测手动操作、休眠和其他调光功能占用。
- 手动关灯保持关闭；手动调整优先 15 分钟。主动查看“当前环境”或学习手动偏好时，可按用户操作额外读取照度。
- 阻止暗处校准值 0 产生全程关灯曲线；旧配置为 0 时保持未开启，需要重新选择非零暗处亮度。
- 新增“调光诊断”：当前/目标亮度、照度、最近自动采样/前光写入、暂停状态和错误详情。

安装：完全退出 KOReader，覆盖 koreader/plugins/einkfrontend.koplugin。重新开启自动调光即可立即开始调整；之后环境变化会在下次一分钟检测时生效。若仍无动作，可查看“设置 → 显示与刷新 → 前光 → 调光诊断”。

验证：119 项本机检查通过，其中新增 12 项调光响应回归，验证立即触发、准确 60 秒周期、逐档调光不额外采样、手动关灯/自动关灯的恢复区别、占用恢复、零值校准和诊断。原有策略测试按新周期更新，保留硬件/存储故障、学习、休眠、模式切换等保护。

用户已确认 0.7.2 的此次现象是响应慢。这里的验证使用 Fengari Lua 5.3 和模拟硬件接口；未执行 Kindle 真机、Linux KOReader/LuaJIT 模拟器或实际浏览器验收。
