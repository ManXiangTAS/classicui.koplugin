# 墨页 · ClassicUI 0.7.1-test.1

自动前光测试版，默认关闭。正式版仍为 0.7.0。

从「设置 → 显示与刷新 → 自动前光」手动启用。先在最暗的阅读环境校准舒适亮度，确认后开启；有光感的设备还会在下拉面板显示快捷入口。无光感或接口不可读时，设置页显示原因，不启动调光。

记忆自适应只学习你在墨页下拉面板里明确做出的亮度调整。停止调整 3 秒后，若照度稳定则保存当前环境的偏好；下次遇到相近光线时局部应用。手动调整后优先保持 15 分钟，可以点「恢复自动」提前结束。手动关灯保持关闭，直到明确恢复。可关闭学习或清除记忆。

Kindle 必须先关闭原生自动亮度，防止争抢控制。光感接口读到数值并不等于所有固件已验证：首次请遮挡、照射传感器，点「当前环境」观察 Lux 是否随光线变化。仍需 Voyage 真机确认普通 / 无框架模式、休眠唤醒和耗电。

完全退出 KOReader 后，将安装包内的 `einkfrontend.koplugin` 覆盖到 `koreader/plugins/`，保留个人设置和书库。适配 KOReader v2026.07.1 / v2026.07.2。
